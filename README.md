# UML_Gen
## 🚀 Getting Started

Follow these steps to set up and run the project locally:

### 1️⃣ Install Requirements

```bash
pip install -r requirements.txt

2️⃣ Download plantuml.jar
Download the latest plantuml.jar file from the official release page:

📦 https://github.com/plantuml/plantuml/releases/latest/download/plantuml.jar

Place it in the root directory of the project.

3️⃣ Get an API Key from Together.ai
Visit Together.ai

Log in or sign up

Copy your API key from the dashboard

Add your API key to your environment ( directly in the code, or via .env).

4️⃣ Run the App with Streamlit

```bash
streamlit run main.py
